# SketchAssist AI API - API reference

Version 3.0.0. *Generated by `scripts/generate_api_docs.py` from the application's OpenAPI schema - do not edit by hand.*

**SketchAssist AI** - multilingual (English / Kannada / Hindi) forensic sketch assistance and case management.

> **Preliminary investigative aid - requires human review.** This system does not identify people. It performs no face recognition, no face matching and no search of photo databases, and its output must never be treated as evidence of identity.

### How to try it
1. `POST /api/auth/register` (the first account becomes the administrator), then use the returned `access_token`
   with the **Authorize** button above.
2. Open a case, parse a description, generate a sketch with `engine=schematic` (rule-based, not AI) and revise it.
3. AI engines need credentials (see `GET /api/engines`); without them they answer **503** with setup steps.

### Conventions
* Errors always look like `{"detail": "...", "code": "machine_code"}` (validation errors add `fields`).
* A case that is not yours looks exactly like a case that does not exist (404).

Live, interactive documentation: `/docs` (Swagger UI) and `/redoc` while the server is running.

### Sketches

#### `POST /api/sketches/generate`

**Generate a sketch (creates a new version)** (Bearer token required)

`engine=schematic` draws a rule-based diagram (NOT AI) and always works. `engine=ai` uses the configured AI engine and returns **503 with setup steps** if none is configured - there is never a silent fallback to the schematic engine. Attributes come from `attributes`, else from the reviewed attributes of `description_id`.

**Request body** (GenerateRequest):

| Field | Type | Required | Description |
|---|---|---|---|
| `case_id` | string | yes | Public case ID, e.g. SA-2026-7K3QWP. |
| `description_id` | integer or null | no | Use this saved description's reviewed attributes. |
| `attributes` | map of string or null or null | no | Attributes to draw. Overrides the description's reviewed attributes if given. |
| `additional_details` | string (maxLength=300) or null | no |  |
| `engine` | `ai` \| `schematic` | yes | 'schematic' = rule-based drawing (not AI). 'ai' = the configured AI engine (needs setup). |

**Responses:** `201` Successful Response, `404` Not Found, `422` Nothing to draw / no supported change in the instruction, `503` The chosen engine is not set up (the body lists the setup steps), `502` The engine failed or returned an unusable image, `429` Too many requests, `409` Conflict

#### `POST /api/sketches/{sketch_id}/revise`

**Revise a sketch with an instruction (creates a new version)** (Bearer token required)

Reads the instruction (English comparatives such as 'thicker eyebrows', explicit values and removals in English, Hindi or Kannada), turns it into attribute changes and draws a **new** version. The version you revise is never modified. Parts of the instruction that could not be applied are listed in `revision_details.ignored`.

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `sketch_id` | path | integer | yes |  |

**Request body** (ReviseRequest):

| Field | Type | Required | Description |
|---|---|---|---|
| `instruction` | string (minLength=3, maxLength=500) | yes | For example: 'make the eyebrows thicker and add glasses'. |
| `language` | string | no |  |
| `engine` | `ai` \| `schematic` or null | no | Defaults to the kind of engine that made the sketch being revised. |

**Responses:** `201` Successful Response, `404` Not Found, `422` Nothing to draw / no supported change in the instruction, `503` The chosen engine is not set up (the body lists the setup steps), `502` The engine failed or returned an unusable image, `429` Too many requests, `409` Conflict

### Datasets and evaluation

#### `GET /api/datasets/status`

**Which datasets are installed, and what is in them** (Bearer token required)

Counts come only from real inspections stored in the database. A dataset that is not installed shows zero records. Nothing is downloaded automatically: the three published face-sketch collections have access restrictions and must be obtained by you under their own terms.

**Responses:** `200` Successful Response

#### `POST /api/datasets/inspect`

**Inspect dataset folders (admin)** (Bearer token required)

Walks the dataset folder, checks that images can be opened and (for the custom dataset) validates every CSV row. Replaces the stored inventory of the inspected dataset with the fresh result.

**Request body** (InspectRequest):

| Field | Type | Required | Description |
|---|---|---|---|
| `dataset_key` | `cufs` \| `cufsf` \| `uom_sgfs` \| `custom_attributes` or null | no | Inspect one dataset, or all if omitted. |

**Responses:** `200` Successful Response, `403` Forbidden, `422` Validation Error

#### `GET /api/evaluations`

**Stored evaluation runs, newest first** (Bearer token required)

Only real runs are stored. The list is empty until an administrator runs an evaluation.

**Responses:** `200` Successful Response

#### `POST /api/evaluations`

**Run the description-parser evaluation (admin)** (Bearer token required)

Parses every valid example of the custom dataset in the chosen split and compares the result with its labels. The number of examples (n) is stored with the metrics. The result carries the limitations of this particular test set.

**Request body** (EvaluationRequest):

| Field | Type | Required | Description |
|---|---|---|---|
| `evaluation_type` | string | no |  |
| `split` | `dev` \| `test` \| `all` | no |  |
| `only_reviewed_translations` | boolean | no | Evaluate only rows whose translation was reviewed by a human. |

**Responses:** `201` Successful Response, `403` Forbidden, `422` Unprocessable Content
