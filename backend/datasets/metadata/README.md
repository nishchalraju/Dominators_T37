# Dataset metadata

`external_datasets.json` describes the published face-sketch collections (CUFS, CUFSF, UoM-SGFS) and the custom demo
dataset: licence, how to obtain them, how to cite them and where their files belong. It is **generated** by
`python scripts/export_dataset_cards.py` from the registry in `app/services/datasets.py` - do not edit it by hand.

It contains no data from the datasets themselves. Nothing is downloaded by this project.
